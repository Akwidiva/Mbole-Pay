This `infra/` folder contains starter files to begin writing Infrastructure as Code for your production environment.

What to do next:
- Add provider blocks for your cloud (AWS/Azure/GCP).
- Add resources for managed Postgres, VPC, and any DNS records.
- Use `terraform init` and `terraform plan` locally, then run in CI for automated provisioning.

This is intentionally minimal — I won't provision anything without your cloud credentials.
